# T7.4: Datos de demostración realistas

## Objetivo
Un comando que llene el sistema con varios meses de operación verosímil de una red bancaria pequeña (casa matriz y tres agencias) para demostrar todos los módulos: libros, IVA, centros de costo, prorrateo, reportes segmentados, tesorería y dashboard.

```bash
docker compose exec backend python manage.py cargar_datos_demo --usuario contador --desde 2026-08-01 --hasta 2026-11-30
```

## Reglas
- **Solo servicios** (`contabilidad`, `tesoreria`, `ventas`, `centros_costo`): nada de inserts directos. Se aplican partida doble, periodo abierto, centro de costo en ingresos y gastos, IVA, asientos contabilizados y bitácora, y los triggers de Oracle no rechazan nada.
- **Periodos cerrados:** si algún mes del rango está cerrado, el comando se detiene **antes de cargar** y lo indica (reabrir es decisión del superusuario).
- **Idempotente:** proveedores y clientes por NIT (o nombre si no hay NIT), compras por proveedor + tipo + número, ventas por tipo + número, asientos manuales por referencia (`PLANILLA-2026-08`, `DEPRECIACION-…`, `SALDOS-INICIALES-DEMO`…). El plan de cada mes se genera con semilla fija (año y mes): el mismo mes da los mismos documentos y montos aunque cambie el rango. Una segunda corrida no crea nada.
- **Datos ficticios:** nombres de empresas y personas inventados; NIT `0614-DDMMAA-NNN-D` y NRC con formato válido.
- Montos `Decimal` en US$, redondeo a centavos.

## Contenido (`config/datos_demo.py`)
| Elemento | Detalle |
|---|---|
| Preparación | `cargar_catalogo_base`, ejercicio si falta, `cargar_centros_base`, `cargar_asignacion_base`, `cargar_prorrateo_base` (cada año), `cargar_flujo_base` |
| Proveedores (18) | Energía, agua, telecomunicaciones (2), vigilancia, traslado de valores, software (2), papelería, imprenta, mantenimiento, aire acondicionado, limpieza, publicidad (2), alquiler de locales, capacitación, equipo de cómputo |
| Clientes (25) | 12 contribuyentes (8 con préstamo empresarial, 4 solo servicios), 12 personas y "Clientes varios (ventanilla)" |
| Apertura (una vez, en `--desde`) | Saldos iniciales: cartera US$21 millones, depósitos US$16 millones, préstamos de otros bancos, activo fijo, patrimonio; aporte de capital de US$1 millón |
| Compras (≈15 por mes) | CCF con IVA; retención del 1 % a proveedores pequeños; factura de consumidor final (IVA al costo); capacitación exenta; equipo de cómputo (activo 1504) trimestral. Centros directos o por regla de asignación |
| Pagos | Cada documento se paga en su vencimiento si cae dentro del rango; los demás quedan pendientes (alimentan la proyección de egresos) |
| Ventas (≈30 por mes) | CCF mensual a cada empresa: intereses del préstamo (exentos) + comisión de manejo (gravada) o servicios empresariales y POS (gravados). Facturas semanales de ventanilla por agencia (intereses de consumo y vivienda exentos + comisiones gravadas) y servicios a personas |
| Planilla (día 28) | 94 empleados en 13 centros; aportes patronales ISSS 7.5 % + AFP 8.75 %; descuentos ISSS 3 % + AFP 7.25 % + renta (aprox. 7 %). Pago de ISSS, AFP y renta el día 10 del mes siguiente. Egresos programados de planilla para la proyección |
| Fin de mes | Intereses sobre depósitos (2.5 % anual, capitalizados); depreciación en línea recta sobre el saldo de 1502/1503/1504; desembolsos, recuperaciones y captación neta |
| Prorrateo | Se ejecuta en cada mes completo del rango después de cargar sus gastos. Si ya estaba ejecutado, se avisa (no se anula nada) |

## Salida
Resumen de lo creado, avisos, totales por mes (asientos, CCF de compra, compras gravadas, IVA crédito fiscal, documentos de venta, total de ventas, IVA débito fiscal) y `verificar_integridad` de cada año; termina con error si hay fallas.
