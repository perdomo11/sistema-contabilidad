# T0.1: Entorno con Docker, Django, React y Oracle

## Objetivo
Dejar el esqueleto del sistema corriendo con `docker compose up --build`, con el frontend mostrando que el backend se conecta a Oracle.

## Estructura de carpetas

## Servicios (docker-compose.yml)
- **oracle-db**: imagen `gvenzl/oracle-xe:21-slim`, contenedor `contable-oracle`, puerto 1521, volumen `oracle-data`, variables `ORACLE_PASSWORD`, `APP_USER`, `APP_USER_PASSWORD`; healthcheck con `healthcheck.sh` (interval 10s, timeout 5s, retries 30, start_period 60s).
- **backend**: build `./backend`, contenedor `contable-backend`, `env_file: .env`, `DB_HOST=oracle-db`, comando `python manage.py migrate && python manage.py runserver 0.0.0.0:8000`, puerto 8000, `depends_on` oracle-db con `condition: service_healthy`.
- **frontend**: build `./frontend`, contenedor `contable-frontend`, puerto 5173, volumen anónimo para `/app/node_modules`, depende de backend.

## Backend
- `requirements.txt`: `Django>=5.2,<5.3`, `djangorestframework>=3.15`, `oracledb>=2.5`, `gunicorn>=22.0`
- Dockerfile: `python:3.12-slim`, `PYTHONDONTWRITEBYTECODE=1`, `PYTHONUNBUFFERED=1`, instala requirements, expone 8000.
- `config/settings.py`: lee todo de variables de entorno; `ENGINE = django.db.backends.oracle` (modo thin), `NAME=XEPDB1` (service name); apps base + `rest_framework`; `LANGUAGE_CODE="es"`, `TIME_ZONE="America/El_Salvador"`; `DEFAULT_AUTO_FIELD=BigAutoField`; renderer JSON.
- `config/health.py`: vista `health` que ejecuta una consulta simple a Oracle (`SELECT banner FROM v$version FETCH FIRST 1 ROWS ONLY`; si no hay permiso, `SELECT 1 FROM DUAL`) y devuelve `{"status":"ok","database":"conectada","version":...}` o 503 con el error.
- `config/urls.py`: `admin/` y `api/health/`.

## Frontend
- `package.json`: React 18.3, react-dom, react-bootstrap 2.10, bootstrap 5.3; dev: vite 5.4, @vitejs/plugin-react 4.3. Script `dev`: `vite --host 0.0.0.0`.
- `vite.config.js`: puerto 5173, `watch.usePolling: true`, proxy `/api` → `http://backend:8000`.
- Dockerfile: `node:20-alpine`, `npm install`, `CMD npm run dev`.
- `App.jsx`: Navbar oscuro "Sistema Contable" y una alerta (verde/roja) que consulta `/api/health/` y muestra el estado de backend + Oracle.
